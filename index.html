ƒ Fórmulas utilizadas en el simulador

Son las ecuaciones que se implementan en script.js (se indica la función donde está cada una). Los ángulos θ se miden desde la vertical hacia abajo; ω = dθ/dt y α = d²θ/dt².

1. Lagrangiano y energías

Código: energias()

L = T − V
d/dt(∂L/∂q̇ᵢ) − ∂L/∂qᵢ = 0, con q₁ = θ₁ y q₂ = θ₂
T = ½ m₁ L₁² ω₁² + ½ m₂ [ L₁² ω₁² + L₂² ω₂² + 2 L₁ L₂ ω₁ ω₂ cos(θ₁ − θ₂) ]
V = −(m₁ + m₂) g L₁ cos θ₁ − m₂ g L₂ cos θ₂
E = T + V

2. Ecuaciones de movimiento

Código: aceleraciones()

δ = θ₁ − θ₂    D = 2m₁ + m₂ − m₂ cos(2δ)
α₁ = [ −g(2m₁ + m₂) sin θ₁ − m₂ g sin(θ₁ − 2θ₂) − 2 sin δ · m₂ (ω₂² L₂ + ω₁² L₁ cos δ) ] / (L₁ · D)
α₂ = [ 2 sin δ · ( ω₁² L₁ (m₁ + m₂) + g (m₁ + m₂) cos θ₁ + ω₂² L₂ m₂ cos δ ) ] / (L₂ · D)
Amortiguamiento opcional: αᵢ ← αᵢ − b · ωᵢ

3. Posición, velocidad y aceleración de las masas

Código: cinematica()

x₁ = L₁ sin θ₁    y₁ = −L₁ cos θ₁
x₂ = x₁ + L₂ sin θ₂    y₂ = y₁ − L₂ cos θ₂
ẋ₁ = L₁ ω₁ cos θ₁    ẏ₁ = L₁ ω₁ sin θ₁
ẋ₂ = ẋ₁ + L₂ ω₂ cos θ₂    ẏ₂ = ẏ₁ + L₂ ω₂ sin θ₂
v = √(ẋ² + ẏ²)
ẍ₁ = L₁ (α₁ cos θ₁ − ω₁² sin θ₁)    ÿ₁ = L₁ (α₁ sin θ₁ + ω₁² cos θ₁)
ẍ₂ = ẍ₁ + L₂ (α₂ cos θ₂ − ω₂² sin θ₂)    ÿ₂ = ÿ₁ + L₂ (α₂ sin θ₂ + ω₂² cos θ₂)
a = √(ẍ² + ÿ²)

4. Integración numérica: Runge-Kutta de 4.º orden

Código: rk4() · paso h = dt = 0,001 s

Estado: y = (θ₁, θ₂, ω₁, ω₂)    y′ = f(y) = (ω₁, ω₂, α₁, α₂)
k₁ = f(yₙ)
k₂ = f(yₙ + h·k₁/2)
k₃ = f(yₙ + h·k₂/2)
k₄ = f(yₙ + h·k₃)
yₙ₊₁ = yₙ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)

5. Resultados derivados

Código: separacion() y deriva()

Separación A–B: d = √[ (x₂,A − x₂,B)² + (y₂,A − y₂,B)² ]
Criterio de caos: d > 0,5 m
Deriva de energía (%) = (E − E₀) / (E₀ − Emín) × 100
Emín = −(m₁ + m₂) g L₁ − m₂ g L₂

6. Validación científica

Código: pruebaEnergia(), pruebaModo()

Oscilaciones pequeñas (m₁ = m₂, L₁ = L₂ = L):
ω² = (g/L)(2 ± √2)
Condición inicial del modo: θ₂ = θ₁ · 2(1 − λ)/λ, con λ = 2 ± √2
Periodo medido: T = 2 (túltimo − tprimero) / (n − 1)    ωsim = 2π / T
Error (%) = |ωsim − ωteórico| / ωteórico × 100

Acerca del modelo

Ecuaciones: L = T − V; Euler-Lagrange: d/dt(∂L/∂q̇ᵢ) − ∂L/∂qᵢ = 0; E = T + V. Se integran con Runge-Kutta de 4.º orden (dt = 0,001 s).

Supuestos: sistema plano, barras rígidas sin masa, masas puntuales, g constante y sin fricción (salvo que actives el amortiguamiento).

Límites: no representa péndulos con masa distribuida ni resistencia del aire real. Ángulos medidos desde la vertical hacia abajo.
